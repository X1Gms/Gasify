# Gasify

## About

Gasify is an IoT project designed to monitor propane gas and carbon monoxide levels in real time.

The main goal is to improve safety by detecting potentially dangerous gas levels and providing users with alerts in case of an emergency. The system was developed around an ESP32-based solution, supported by software components for data communication and monitoring.

## Main Goals

- Monitor propane gas levels.
- Monitor carbon monoxide levels.
- Receive and process sensor information.
- Provide alerts when potentially dangerous levels are detected.
- Explore communication between hardware and software components.

## Technologies

- **Java** – Android application development.
- **JavaScript, HTML and CSS** – Web interface technologies.
- **ESP32-S3** – Hardware and sensor integration.
- **MQTT** – Messaging and communication.
- **Android** – Mobile application platform.

## Project Structure

The repository is organized into different components:

- `android/` – Android application.
- `backend/` – Backend component.
- `esp32/` – ESP32 hardware-related code.
- `mqtt_server/` – MQTT server component.

## What I Learned

Through this project, I had the opportunity to explore:

- IoT concepts and hardware integration.
- Communication between different software components.
- MQTT messaging.
- Android application development.
- The challenges of building a system that connects hardware and software.

## Disclaimer

Gasify is an academic project and should not be considered a certified gas detection or emergency response system.
